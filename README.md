\# HabitFlow Pro



A professional offline-first habit tracker built for Windows, Android, and modern browsers.



\## Tech Stack



\### Frontend

\- HTML5

\- CSS3

\- JavaScript

\- Chart.js

\- FullCalendar

\- PWA



\### Backend

\- FastAPI

\- SQLAlchemy

\- SQLite

\- JWT Authentication



\## Features



\- Daily, Weekly, Monthly, Yearly Tracking

\- Dashboard

\- Calendar

\- Analytics

\- Journal

\- Achievements

\- Offline Support

\- Cloud Sync Ready

\- Responsive Design
